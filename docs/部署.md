## 结构

一台服务器、一个 `docker compose`：

| 服务 | 干什么 |
|---|---|
| `db` | PostgreSQL 17，数据存在 `pgdata` 卷里 |
| `app` | 本仓库的 Next.js 应用（`Dockerfile` 三段构建，standalone 输出） |
| `caddy` | 反向代理；`SITE_ADDRESS` 是 `:80` 时用 IP 访问，是域名时自动申请 HTTPS 证书 |
| `tools` | 平时不启动；跑迁移、灌演示数据时临时用 |

## 第一次部署

```bash
# 1. 服务器上装 Docker（Ubuntu 24.04）
curl -fsSL https://get.docker.com | sh

# 2. 拉代码
git clone https://github.com/2770419748-lgtm/dianyoushu-erp.git && cd dianyoushu-erp

# 3. 写 .env（不进仓库）
cat > .env <<'ENV'
POSTGRES_PASSWORD=换成一长串随机字符
SESSION_SECRET=换成另一长串随机字符
SITE_ADDRESS=:80
ENV

# 4. 起数据库、建表、灌演示数据（约 1 分钟）
docker compose up -d db
docker compose run --rm tools pnpm exec prisma migrate deploy
docker compose run --rm tools pnpm db:reset

# 5. 起应用和 Caddy
docker compose up -d --build app caddy
```

浏览器打开 `http://服务器IP`，用 README 里的演示账号登录。

## 备案下来、有域名以后

1. 域名解析：A 记录指向服务器 IP。
2. `.env` 里 `SITE_ADDRESS=你的域名`，然后 `docker compose up -d caddy`，Caddy 会自动申请证书，`https://你的域名` 就能打开。
