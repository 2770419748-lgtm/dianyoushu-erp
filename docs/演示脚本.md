# 10 分钟演示脚本

对应方案第 12 节的演示路径。目标：10 分钟内走完，不出错。建议排练 3 次并计时，每次把用时记在最后的表里。

## 演示前一晚

1. `pnpm db:reset`：清空重来，生成截至昨天的 3 个月经营数据。今天没有任何单据，现场开的第一单就是今天的第一单，看板上“今日销售”从 0 变成这单的金额。
2. 重置之后**不要再跑** `pnpm test:e2e`，它会在今天开单再作废，日结列表里会多出几张作废单。
3. `pnpm dev` 启动，电脑浏览器开两个窗口：一个登 `hq`（总部），一个准备切店员和店长。
4. 手机上演示：电脑改跑 `pnpm dev:https`，手机连同一个 Wi-Fi 打开地址并登录 `staff`（见 README“手机上测试”）。没有手机就在电脑浏览器按 F12 切成手机尺寸，打开 `/m/sale`。

所有演示账号密码都是 `demo1234`：`hq` 总部、`manager` 中山路店店长、`staff` 中山路店店员。

## 现场容易卡的地方

- 第 3 步收货要用 `manager`，它只管中山路店（S001），所以采购要进 S002、再调到 S001。
- 第 4 步旧机的码不能和库里已有的重复；重复了会提示，换一个 SN 就行。
- 第 6 步确认日结之后，S001 今天就不能再开单了。要重来，用 `hq` 在日结页撤销（写原因）。
- 手机摄像头扫码要 HTTPS；扫不出来就直接输码，同一个入口。
