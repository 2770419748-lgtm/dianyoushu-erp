# 店有数 ERP

[![CI](https://github.com/2770419748-lgtm/dianyoushu-erp/actions/workflows/ci.yml/badge.svg)](https://github.com/2770419748-lgtm/dianyoushu-erp/actions/workflows/ci.yml)

手机零售门店经营系统的演示版：从采购入库、串号库存、调拨盘点、门店开单（含以旧换新）到收银日结、经营看板，一条业务链跑通。四种角色各看各的数据，店员用手机扫码开单。

和桌面版“店有数”（仓库 `dianyoushu`，已经在门店日常使用的经营数据工具）是两个项目：桌面版给一家店自己用，店有数 ERP 是多门店、多角色、带完整进销存链路的版本。

## 演示

- 演示地址：还没上线，现在用本机演示（上线安排见任务清单“找工作前再做”）。
- 10 分钟演示路径：`docs/演示脚本.md`。
- 演示账号，密码都是 `demo1234`：

| 账号 | 角色 | 能看什么 |
|---|---|---|
| `hq` | 总部 | 全部 10 家店，能管组织、商品、采购、KPI |
| `regional` | 区域经理 | 华东区 4 家店，只看不改 |
| `manager` | 店长 | S001 中山路店：调拨、盘点确认、日结、改价 |
| `staff` | 店员 | S001 中山路店：开单、退货、收旧机、盘点录入 |

这 4 个账号受保护，不能被改密码、停用或改角色；想试这些功能先用 `hq` 新建一个员工。`demo1234` 只是演示用的公开密码：本机和上线后的演示站都用它，演示站每天重置数据；拿去给真实门店用之前必须改掉所有密码，做法见 `docs/部署.md`“演示账号和密码”。

## 做了什么

| 模块 | 能做什么 |
|---|---|
| 登录与权限 | 账号密码登录、错 5 次锁 15 分钟；四种角色，数据范围在服务端按门店过滤；操作日志 |
| 组织 | 区域 → 门店 → 员工三级树，新增、编辑、停用、重置密码 |
| 商品 | 品类、品牌、型号、SKU（颜色、容量）；指导价 + 门店售价 |
| 采购入库 | 采购单草稿 → 提交 → 到货（可分批）；每台机器录 SN、IMEI1、IMEI2，可粘贴可扫码 |
| 库存 | 串号库存、配件库存、低于安全库存标红；每次增减都有流水，一台机器从入库到卖出全程可查 |
| 调拨与盘点 | 申请锁定 → 发出在途 → 按码收货；盘点快照应有、录实盘、自动算盘盈盘亏 |
| 开单 | 电脑版：选客户、加机器配件、改价优惠、以旧换新抵扣、多种收款拆分；手机版：扫码加商品、一屏提交 |
| 回收与退货 | 现场收旧机抵扣、回收机转良品再卖；按原单退货、按原收款方式退款 |
| 日结 | 按支付方式对账、逐单比对、差异标红、确认后锁单，收银日报导出 |
| 看板 | 日销趋势、门店月销对比、员工排名、热销机型、KPI 完成率与每天还差多少、库存周转与滞销 |
| 其他 | KPI 目标录入、后续规划页（没做的模块和原因）、PWA 可添加到手机桌面 |

模拟数据：10 家店、100 个员工、截至昨天 3 个月约 1.2 万张销售单、1500 张回收单，全部随机生成，不含真人信息。

## 技术

Next.js 16（App Router）+ TypeScript + Prisma 7 + PostgreSQL 17 + Ant Design 6 + ECharts；单仓库单进程，业务规则全部在 `src/server/` 服务层。测试：Vitest（单元测试和连库测试，跑完回滚）+ Playwright（电脑开单到日结、手机开单两条端到端）；GitHub Actions 起一个临时 PostgreSQL，跑 lint、类型检查、全部测试（含连库、并发、回归）和生产构建。部署用 Docker Compose（PostgreSQL + 应用 + Caddy 自动 HTTPS），写好了还没上线。

为什么这么选、为什么不做 App 和人事：`docs/取舍记录.md`。

## 本地运行

1. 装好 Node 24、pnpm、PostgreSQL 17，在 PostgreSQL 里建一个空库 `dianyoushu_erp`。
2. 把 `.env.example` 复制一份改名 `.env`，填上数据库密码和一串随机的会话密钥。
3. `pnpm install`（装完会自动生成 Prisma 客户端）。
4. `pnpm db:migrate` 建表。
5. `pnpm db:reset` 灌入模拟数据，约 30 秒。
6. `pnpm dev`，浏览器打开 http://localhost:3000 。

## 手机上测试

手机浏览器只在 HTTPS 页面里给摄像头，扫码要这样开：

1. 电脑和手机连同一个 Wi-Fi。
2. 关掉 `pnpm dev`，改跑 `pnpm dev:https`。第一次会用 openssl（装了 Git for Windows 就有）给电脑的局域网 IP 签一张本机测试证书，不装根证书、不改系统设置。
3. 手机浏览器打开终端里打印的地址（例如 `https://192.168.1.8:3000`），提示“不安全”时点“高级 → 继续访问”。Windows 弹防火墙提示选“允许”。
4. 登录后点首页的“手机开单”或“查库存”，点“扫码”对准串号条码。想像 App 一样用：浏览器菜单里选“添加到主屏幕”。
